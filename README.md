# AquaMed360 Climate-Health Early Warning Prototype

AquaMed360 is an early-stage open-source climate-health risk intelligence prototype developed by Catalyst Innov Dev Ltd to support vulnerable children in climate-affected coastal communities.

The prototype demonstrates:

- Community-level child climate-health risk scoring
- Flood, water contamination, malaria and heat-risk monitoring
- Live weather signal integration
- Automated climate-health alert generation
- Field validation pathway through the Foundation for Climate Action and Agriculture Initiative

## Target Users

- Community health workers
- Schools
- Caregivers
- Local health and environment teams
- Humanitarian responders

## Prototype Communities

- Ayetoro
- Abereke
- Etugbo

## Technology Stack

- Streamlit
- Python
- Pandas
- Open weather data signal
- GitHub-hosted open-source prototype files

## Open-Source Commitment

Catalyst Innov Dev Ltd intends to release the core risk-scoring logic, implementation notes and non-sensitive documentation under an open-source licence.

## Field Validation Pathway

The Foundation for Climate Action and Agriculture Initiative will support community entry, safeguarding, field feedback, data validation and pilot learning in coastal communities in Ondo State, Nigeria.

## Status

This is an early-stage working prototype for demonstration, learning and field validation.
